ui-clean-arch

Uma arquitetura de frontend organizada por telas

Cada tela é um domínio que reúne:

Components
Interface e interações locais
Store
Coordenação do estado da tela
Services
APIs, armazenamento e integrações
Entities
Adaptação e formatação de dados

UI e comportamento

UI

Components exibem a interface e cuidam das interações locais.

Use o framework que fizer sentido para o projeto.

React, Vue, Angular, Svelte…
ou JavaScript sem framework.

Comportamento

Store
Coordena o estado da tela.
Services
Acessam integrações externas.
Entities
Adaptam e formatam dados.

Essas camadas são agnósticas: não dependem do framework de UI.

O framework fica na UI. O comportamento mantém seus contratos ao trocar a tecnologia da interface.

UI / Components

Components formam a interface. Cada seção com um contexto próprio é um Component.

Comportamento / Stores

A Store coordena o estado compartilhado entre os Components da tela.

Comportamento / Services

Funções assíncronas que conectam a aplicação a recursos externos.

Comportamento / Entities

O Service usa a Entity para entregar dados no formato que a tela precisa.
